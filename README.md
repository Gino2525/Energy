
This project focuses on optimizing energy consumption by leveraging AI and machine learning techniques. The goal is to analyze historical energy usage patterns, forecast future consumption, and classify usage behavior into meaningful clusters (e.g., low, medium, high). By using models like XGBoost, Prophet, and clustering algorithms, the system provides intelligent insights that help users reduce wastage and manage energy more efficiently. The solution also includes a Django-based backend with APIs and a React frontend to deliver real-time, user-friendly visualizations and predictions.
